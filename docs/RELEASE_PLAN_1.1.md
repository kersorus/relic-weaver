## Release gate

1. Фон остаётся в масштабе `Vector2.ONE` и не меняет геометрию между кадрами.
2. Любой смертельный урон немедленно показывает `0` и пустую полосу HP.
3. Предмет можно переместить, объединить и купить перетаскиванием; управление тапами продолжает работать.
4. Автораскладка не уменьшает рассчитанную силу сборки.
5. Импульс связи заряжается, наносит урон, лечит, прерывает врага и расходует заряд.
6. Первый запуск показывает пять страниц обучения, которое можно повторить из настроек.
7. Все экраны читаются в portrait viewport 720×1280 и окне 360×640.
8. Релиз содержит APK и самостоятельные Linux/Windows бинарники без внешних PCK.
