# Relic Weaver 1.1.1 — release gate

Цель патча: закрыть системные риски, которые не требуют нового контента, перед дальнейшим расширением кампании.

## Надёжность

- [x] Сохранение сначала записывается во временный файл и проверяется как JSON.
- [x] Последняя корректная версия хранится отдельно и используется при повреждении основного файла.
- [x] Бой автоматически ставится на паузу при сворачивании игры или потере фокуса.
- [x] Разбор предмета требует подтверждения и заранее показывает возврат деталей.

## Доступность и удобство

- [x] Выбранная скорость боя сохраняется между сражениями.
- [x] Тактильный отклик можно отключить в настройках.
- [x] Типы связей различаются формой маркера, а не только цветом.
- [x] Подсказки мастерской и обучения объясняют новые обозначения.

## Проверка релиза

- [x] Импорт проекта и GDScript lint проходят на Godot 4.3.
- [x] Headless boot достигает `RELIC_WEAVER_BOOT_OK`.
- [x] Gameplay suite достигает `RELIC_WEAVER_RELEASE_CHECKS_OK` без утечек ресурсов.
- [x] Визуальный smoke test подтверждает мастерскую, настройки и бой в 360×640.
- [x] CI останавливает экспорт при любом `ERROR:` от Godot, а не только при ошибке GDScript.
- [ ] GitHub Actions собирает Android, Linux и Windows.
- [ ] Тег `v1.1.1` публикует релиз с бинарниками и `SHA256SUMS.txt`.
