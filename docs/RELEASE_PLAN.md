# Relic Weaver — план релиза 1.0

## Цель релиза

Версия 1.0 должна быть законченной офлайн-игрой, а не обещанием будущей игры: запускаться без серого экрана, давать завершённую кампанию, сохранять прогресс, объяснять главную механику связей, выглядеть цельно на мобильном экране и собираться для Android, Linux и Windows одной воспроизводимой CI-цепочкой.

## Выполненный план

- [x] **P0 — запуск и диагностика.** Устранить parse/runtime-блокеры, сохранить видимый boot fallback и требовать `RELIC_WEAVER_BOOT_OK` в CI.
- [x] **P0 — путь игрока.** Автоматически проверить домашний экран, создание забега, мастерскую, бой, победу и выбор награды.
- [x] **P1 — сохранения.** Версионировать и нормализовать save, ограничить испорченные значения, сохранять активный забег и незабранную награду.
- [x] **P1 — честный core loop.** Уникализировать награды, реализовать заявленный эффект клинка, прекратить события боя после смертельного удара, убрать фарм Искр через мгновенный выход.
- [x] **P1 — UX.** Добавить прокрутку длинных экранов, подтверждение выхода, паузу боя, настройки SFX, reduced motion и встряски.
- [x] **P1 — читаемость билда.** Показывать активные связи на сетке, выделять выбранную клетку и сохранять понятное описание предмета.
- [x] **P1 — полная кампания.** Довести историю до четырёх глав и 20 боёв, добавить финальную локацию, трёх противников и законченный эпилог.
- [x] **P2 — арт-полировка.** Привести окружения к одной тёмной пиксельной палитре, добавить глубину, ambient motion, grounding персонажей, hit/merge/loot feedback.
- [x] **P2 — доступность и мета.** Ограничить постоянные улучшения, разделить открытые и завершённые записи архива, дать повторный запуск обучения.
- [x] **Release gate.** Godot 4.3 import, boot smoke и release checks прошли без `SCRIPT ERROR`; GitHub Actions run №7 собрал Android, Linux и Windows; релиз зафиксирован тегом `v1.0.0`.

## Критерии готовности

1. Главная сцена достигает `RELIC_WEAVER_BOOT_OK` на Godot 4.3.
2. `tests/release_checks.gd` заканчивается маркером `RELIC_WEAVER_RELEASE_CHECKS_OK`.
3. Ни import, ни boot, ни игровой маршрут не содержат `SCRIPT ERROR`.
4. Все предметы, противники, props и фоны существуют и импортируются.
5. Старый save 0.3 открывается без сброса валюты и улучшений; некорректные значения ограничиваются.
6. Незаконченный забег можно продолжить; финальную победу нельзя потерять закрытием приложения.
7. Интерфейс читаем на базовом portrait viewport 720×1280 и окне 360×640.
8. GitHub Actions публикует Android/Linux/Windows artifacts и checksums, а тег `v1.0.0` создаёт GitHub Release.

## После 1.0

Возможные обновления не являются долгом релиза: frame-by-frame sprite sheets, предметы нестандартной формы, дополнительные герои, ежедневные seeded-забеги и полноценный музыкальный саундтрек.
