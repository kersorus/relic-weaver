# Relic Weaver 1.2 — Берег оборванных дорог

Цель версии: после закрытия системного долга расширить законченную кампанию новым содержательным эпилогом, не ломая существующую игровую петлю.

## Контент

- [x] Пятая глава продолжает финал Первого узла и содержит пять боёв.
- [x] Три новых противника используют отдельные, явно описанные боевые особенности.
- [x] Три новых артефакта открывают сборки через силу и скорость Импульса, а также замедление врага.
- [x] Новое вертикальное окружение сохраняет свободный передний план для боя и интерфейса.
- [x] Все новые изображения приведены к размерам и прозрачности существующего каталога.
