# Relic Weaver — Узлы старого мира

Небольшой полностью офлайн vertical-slice merge / backpack / auto-battler RPG на Godot 4.

Игра использует знакомую жанровую петлю «собери билд → слей дубликаты → автобой», но не копирует контент, персонажей, интерфейс или экономику Overgeared Hero. Главная отличительная механика — **связи соседства**: положение артефактов на поле влияет на их свойства, а `Связующая нить` буквально усиливает соседние предметы.

## Что уже работает

- 3 сюжетные главы по 5 боёв;
- 7 типов противников и 2 варианта босса;
- 12 оригинальных предметов;
- сетка мастерской 5×4;
- покупка предметов, перестановка тапами, swap и merge T1→T4;
- синергии соседства и отдельные эффекты предметов;
- автобой: атака, крит, броня, уклонение, вампиризм, регенерация, магические импульсы, оглушение;
- награды после боя и предмет после победы;
- 3 постоянных улучшения за обычную игровую валюту;
- локальный save в `user://relic_weaver_save.json`;
- полностью офлайн, без рекламы, серверов, аккаунтов и SDK аналитики;
- portrait UI под 720×1280, мышь и touch;
- оригинальные PNG-ассеты и WAV-звуки лежат в `assets/`.

## Управление

В мастерской:

1. Купи предмет внизу экрана.
2. Тапни по предмету на сетке.
3. Тапни по другой клетке:
   - пустая клетка — перенос;
   - другой предмет — обмен местами;
   - такой же предмет того же T-уровня — слияние.
4. Нажми **В БОЙ**.

В бою управление не требуется: результат определяется собранным билдом.

## Запуск

Нужен Godot 4.3+.

```bash
godot --editor project.godot
```

Либо просто открыть `project.godot` в редакторе Godot и нажать Run Project.

## Android

Проект использует `gl_compatibility` и portrait viewport. В Godot установи Android build template, добавь Android preset через **Project → Export**, после чего можно собирать APK/AAB обычным способом.

Сейчас `export_presets.cfg` намеренно не зашит: пути к SDK/JDK и подписи сильно отличаются между машинами. Код игры не требует Android-плагинов.

## Загрузка на GitHub из Termux, когда репозитория ещё нет

Самый короткий вариант — через GitHub CLI:

```bash
pkg update
pkg install git gh unzip
termux-setup-storage
cd ~/storage/downloads
unzip relic_weaver.zip
cd relic_weaver

git init -b main
git add .
git commit -m "Initial playable Relic Weaver prototype"

gh auth login
gh repo create relic-weaver --private --source=. --remote=origin --push
```

Если репозиторий должен быть публичным, замени `--private` на `--public`.

Для следующих изменений:

```bash
git add .
git commit -m "Gameplay update"
git push
```

## Архитектура

- `src/main.gd` — UI, run state, магазин, merge, расчёт билда и бой;
- `src/game_data.gd` — предметы, главы, противники и формулы tiers;
- `src/save_manager.gd` — локальное JSON-сохранение;
- `assets/items/` — иконки предметов;
- `assets/actors/` — герой и противники;
- `assets/backgrounds/` — фоны трёх глав;
- `assets/audio/` — короткие оригинальные SFX.

## Что логично делать следующим

1. Drag-and-drop как альтернативу тапам и подсветку будущего merge.
2. Несимметричные предметы 1×2 / 2×2 и вращение — это резко увеличит глубину сетки.
3. Выбор одной из 3 наград после элитного боя.
4. Активные «жесты связи» между боями вместо обычных ультимейтов.
5. Ещё 2 героя с разными правилами мастерской, а не просто разными статами.
6. Seeded runs и локальные испытания дня без подключения к сети.
7. Полноценная пиксельная анимация и музыка.

## Примечание о прототипе

В окружении, где был собран этот архив, бинарника Godot нет, поэтому проект прошёл структурную проверку файлов и ссылок на ресурсы, но не запускался движком автоматически. Он рассчитан на Godot 4.3+; если твоя конкретная версия Godot покажет ошибку совместимости API, исправление должно быть небольшим и локальным.
